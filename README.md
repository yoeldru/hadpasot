# הדפסות

אפליקציית אנדרואיד להדפסה מהטלפון לכל מדפסת ברשת, או לקובץ PDF.

## מה יש בה
- **חיבור למדפסת**: סריקת רשת אוטומטית (Bonjour + סריקת כתובות), הוספה לפי IP, פרוטוקולים IPP / IPPS / RAW 9100.
- **קבצים**: PDF, תמונות (כולל HEIC), טקסט, וורד / אקסל / פאוורפוינט / RTF / HTML (המרה דרך Apps Script). כמה קבצים בעבודה אחת, שינוי סדר.
- **אפשרויות**: עותקים ואיסוף, טווח עמודים, זוגיים/אי-זוגיים, סדר הפוך, גודל נייר, לאורך/לרוחב, 1/2/4/6/9/16 עמודים בדף (גם מימין לשמאל), מסגרות, קנה מידה, שוליים, צבע/שחור-לבן, איכות, מספרי עמודים, סימן מים.
- **דו-צדדי**: ע"י המדפסת, או ידני (מדפיס צד אחד, מבקש להפוך ערימה, מדפיס את השני).
- **חוברת**: כריכה מימין (עברית) או משמאל, חלוקה לקונטרסים, רווח בקיפול.
- **תצוגה מקדימה** של כל גיליון (קדמי/אחורי), עם הגדלה.
- מצב המדפסת ומפלסי דיו/טונר, דף ניסיון, הגדרות שמורות, היסטוריה עם "הדפס שוב".
- שיתוף לאפליקציה מכל מקום, שמירה/שיתוף PDF, הדפסה דרך שירות ההדפסה של אנדרואיד.
- התראה על גרסה חדשה (נקודה אדומה) ושיתוף האפליקציה.

## בנייה
כל דחיפה ל-`main` בונה APK ב-GitHub Actions ומפרסמת אותו כ-Release:
`https://github.com/yoeldru/hadpasot/releases/latest/download/hadpasot.apk`

## שירות ההמרה (וורד וכו')
הקוד נמצא ב-`apps-script/Code.gs`. ההוראות המלאות באפליקציה: הגדרות ← שירות המרה.
